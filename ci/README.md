# CI Notes

Most of my repos do not need much here.

My default preference is:

- use scripts first
- add GitLab CI only when I need deploy/test automation

## Included Starters

- `ci/profiles/application.md`
- `ci/profiles/infrastructure.md`
- `.gitlab-ci.yml`

Use them only if they help.

If the repo does not need CI, this folder can stay minimal or be removed.
