# Security Policy

## Reporting a vulnerability

Please **do not open a public issue**. Use GitHub's private reporting:
<https://github.com/OWNER/REPO/security/advisories/new>

Never include passwords, tokens, keys, state files or real hostnames in issues
or pull requests; use redacted values. You can expect an initial response
within a few days.

## Supported versions

Only the latest `main` receives security fixes.
